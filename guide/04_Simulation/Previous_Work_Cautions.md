# Previous work that must not be mistaken for a validated simulator

The original `BN_C_Aerogel_Simulation_Plan.xlsx` contains literature-derived and exploratory settings. Its formulas only compute comparison ratios/statuses; it is not a PDE solver. Its low-k targets describe dry insulation references, not proven properties of the resin-infiltrated project laminate.

Its “BN fraction 25%” and “BN:C 1:1” baseline are inconsistent if both mean the same two-component mass basis. Neither has a sufficiently defined denominator. Porosity, density and channel geometry also require a consistent phase mass balance; do not independently enforce every displayed number.

The original HTML aerogel demos use geometric construction and interpolation controls. Review the source before reuse; the retained files do not establish validated heat-transfer predictions. Some use external JavaScript/CDN resources and may need network access. Keep geometry visualisation separate from physical model validation. The `_fixed` demo is a preserved later file, not a certification of scientific correctness.

Older research master and database verification labels describe their original 8 October retrieval, not a fresh audit of all 49 records. Preserve original provenance and dates. The current reference catalog adds explicit offline availability and only upgrades metadata actually checked in this run.

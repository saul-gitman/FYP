Processing–Structure–Property Framework

CFRP with carbon-aerogel interlayer and BN reflective surface

1. Processing / Control Parameters

  • BN:C ratio / filler composition
  • BN loading in reflective surface layer
  • CNT loading in carbon-aerogel interlayer
  • CNF concentration / total solids content
  • MTMS content
  • Freezing temperature
  • Freezing time
  • Freeze-drying pressure and duration
  • Dispersion / sonication conditions
  • Slurry mixing time and speed
  • Aerogel / surface-layer target thickness
  • Resin infusion pressure and direction
  • Curing / post-curing condition
Controllable fabrication variables. Keep the category fixed; revise the listed variables as the experimental plan is refined.

2. Resulting Structure

  • Pore size and pore-size distribution
  • Pore morphology / geometry
  • Pore alignment and structural anisotropy
  • Porosity
  • Bulk density
  • Drying shrinkage
  • Layer thickness and thickness uniformity
  • BN / CNT dispersion and agglomeration
  • Interfacial bonding with CFRP
  • Resin infiltration / residual void fraction
  • Surface morphology / roughness
Measured morphology after fabrication. “Hexagonal” should only be used if microscopy actually shows a reproducible hexagonal pore or cell geometry.

3. Resulting Properties

  • Through-thickness effective thermal conductivity, kz
  • Area-normalized thermal resistance, R″z
  • Steady-state heat-source temperature rise
  • Transient heating / cooling response
  • Surface temperature distribution / heat spreading
  • Solar-weighted reflectance
  • Spectral reflectance (UV–Vis–NIR)
  • Temperature rise under solar irradiation
  • Thermal–optical coupled cooling performance
  • Mechanical performance (e.g. short-beam / interlaminar strength)
  • Areal mass / mass penalty
Final measurable performance. Use tensile strength only if tensile testing is actually included; the current plan is more directly aligned with short-beam / interlaminar mechanical evaluation.

Demo only：呢個模型係用嚟理解參數，唔係物理預測。 真實世界入面 concentration、porosity、density 等會互相影響；呢度刻意分開畀你逐樣玩。

Adjustable parameters

BN : C ratio 50 : 50

只代表固體部分入面 BN 同 Carbon 嘅比例。向左 = 多 Carbon；向右 = 多 BN。

Total concentration 10 wt%

製作前液體/混合物入面有幾多固體材料。高 concentration = 起步時有更多 BN + C。

Porosity 98.0%

乾咗之後，成個 aerogel 有幾多體積係空位。98% 即係大部分都係空。

Pore size 60 μm

孔道大概有幾闊。細 pore = 結構更密；大 pore = 孔道更疏、更闊。

Density 25 mg/cm³

同一體積嘅乾 aerogel 有幾重。高 density = 同一大小入面有更多固體質量。

What each parameter actually means

BN : C ratio

呢個係「材料配方」。例如 70:30 即係固體骨架入面，概念上以較多 BN、較少 Carbon 組成。 佢唔代表總共落咗幾多料。

Total concentration

呢個係「一開始混合物有幾濃」。例如 10 wt% 即係製作前混合物中，固體 BN + C 佔一定重量比例。 真實製作時佢會影響最後骨架、孔同密度，但呢個 demo 暫時分開顯示。

Porosity

呢個係「最後有幾空」。Porosity 越高，代表同一體積入面空間越多、固體越少。 3D demo 會用更薄嘅骨架去表示高 porosity。

Pore size

呢個係「一個孔大概有幾闊」。Pore size 越大，畫面中孔道間距會變大、孔數會減少。 呢個只係簡化表示，唔係 SEM 重建。

Density

Density 係「每一個體積有幾多質量」。同樣大小嘅 aerogel，density 越高就越重。 Demo 會用更多/更實嘅固體粒子去表示。

Why these are separate here

真實材料入面呢幾個數值唔係完全獨立，例如 concentration 改咗，最後 porosity 同 density 通常都會跟住變。 但第一版 demo 分開控制，目的係先搞清楚「每一粒掣究竟代表咩」。
